# Miyu built-in semantic model (miyu-embed)

> <sub>This document was generated by Anthropic's Claude Fable 5.2.</sub>

This repository is the built-in semantic model of [Miyu](https://github.com/miyu-agent/miyu): a small package with a program, `embed`. It searches memories and the knowledge base by meaning on your own computer, without going online. To install it, run:

```sh
miyu pkg install embed
```

A few things to know about this package:

- The program `miyu-embed`: it loads an ONNX model according to the model manifest `package/embed/model.toml` (ONNX Runtime is statically linked into the program), reads one sentence per line from standard input, and writes one vector per line to standard output. The protocol is described in point four of `internal/blueprint/recall.md` in the core repository.
- The model: a 4-bit quantization of `granite-embedding-97m-multilingual-r2` (Apache-2.0). The files are in this repository's release `models-granite-embedding-97m-multilingual-r2`, and `tools/quantize_q4.py` and `tools/bpe_files.py` reproduce them byte for byte.
- Publishing a new version: push the tag `v<version>`; `release.yml` builds one package file for each system following the official packaging template, and the package source picks up new releases once a day.
- Dependencies: the package depends on the core's `miyu-recall` (the types of the model manifest), pinned through git to one commit of the core; to upgrade the core, change `rev` in `Cargo.toml`, refresh `Cargo.lock`, and pass CI.
